# nodefony-upgrade

> Ce fichier est un **pointeur**, posé par `nodefony ai:sync`. Le contenu vit
> dans le paquet `@nodefony/devkit` et se met à jour par `npm update` —
> ne l'édite pas ici, l'édition serait écrasée et ne profiterait à personne.

**Lis maintenant `node_modules/@nodefony/devkit/skills/nodefony-upgrade/SKILL.md`** : c'est la version qui correspond à la
version du framework installée dans ce projet.
